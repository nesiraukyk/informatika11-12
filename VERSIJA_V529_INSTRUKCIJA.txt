- Mokytojo puslapyje didelė antraštė MOKYTOJO APLINKA be sveikinimo teksto.

DIEGIMAS:
1. Išarchyvuokite ZIP.
2. Į GitHub repo šaknį įkelkite VISĄ aplanko informatika11-12-main TURINĮ, ypač index.html, app.js, style.css.
3. Sulaukite, kol GitHub Pages baigs publikavimą.
4. Atidarykite https://ngg-informatika.lt/?v=5.29.0 (jei reikia, Ctrl+Shift+R).
5. Jei vis dar senas vaizdas, patikrinkite šaltinį: View page source -> app.js?v=5.29.0.
